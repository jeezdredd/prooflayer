# Manipulation map (EXPERIMENTAL, not in the roster)

> [!warning] Experiment only
> Code lives in `backend/analyzers/manipulation/` on branch `exp/manipulation-map`. Nothing here is
> registered in `seed_analyzers`, nothing runs on uploads, and the UI still shows the JPEG-only ELA
> heatmap. Numbers below come from a bounded local evaluation on a shared CPU; see
> [[analyzers/manipulation-map-results]] for every table.

Goal: show WHERE a real-looking photo was changed (pasted from another picture, copied inside the same
picture, or regenerated by AI inpainting / generative fill), and show nothing when unsure. A wrong map on an
honest photo is worse than no map, so false alarms on authentic photos are measured first and the map
abstains by default.

## Pieces

| module | method | licence | role in the map |
|---|---|---|---|
| `catnet.py`, `catnet_net.py` | CAT-Net v2 (Kwon et al., IJCV 2022), HRNet RGB stream + JPEG DCT stream | code Apache-2.0, weights CC-BY 4.0 (README update 2026-08-05) | learned map; strongest single method on pasted-back AI inpainting |
| `safire.py`, `safire_net.py` | SAFIRE (Kwon et al., AAAI 2025), SAM ViT-B with adaptors, 8x8 point grid, 2-cluster split | code Apache-2.0, weights CC-BY 4.0 | second learned map, only counted when it agrees with CAT-Net |
| `jpeg_grid.py` | ZERO (Nikoukhah et al., IPOL 2021) re-implemented from the article | own code (official code is AGPL, not used) | a-contrario "foreign JPEG grid" and "missing JPEG grid" regions |
| `copymove.py` | SIFT + a-contrario patch matching (Ehret 2019) re-implemented | own code + OpenCV SIFT (Apache-2.0) | "copied inside the image" pairs |
| `ai_tiles.py` | Community Forensics ViT-S/16 on 384 px tiles | MIT (already shipped) | only adds a "looks AI-generated" label to an accepted region |
| `fusion.py`, `regions.py` | gating, calibration hooks, abstain rules | own code | one per-pixel map, region list, image score, abstain flag |
| `pipeline.py` | `run_methods`, `analyze_bytes` | own code | pure entry point for a future analyzer |

Licences, weight sha256 and attribution text: `backend/analyzers/manipulation/THIRD_PARTY.md`.

Excluded on licence: TruFor, Noiseprint(++), Splicebuster, B-Free, ZED (GRIP non-profit licence; TruFor
also builds on non-commercial SegFormer), MMFusion-IML (academic only), Mesorch and IML-ViT (fine-tuned from
non-commercial SegFormer / MAE weights), MVSS-Net, ManTra-Net, BusterNet and others with no licence or no
weights, SIDA, FakeShield, SICA (licence and/or tens of GB of VRAM). The ZERO, Noisesniffer and IPOL
copy-move reference codes are AGPL/GPL, so only the papers were used.

## How a map is decided (`fusion.fuse`)

1. Abstain before looking: not a photo (`is_photo=False`), short side under 384 px, or the Tribunal verdict
   for the whole image is fake / likely fake (the map would only repeat "everything is AI").
2. JPEG quality under 70: only copy-move may produce a region (JPEG-trace methods are blind there).
3. A region is accepted when one of these holds:
   - copy-move group with at least `copymove_min_matches` a-contrario matches (label `copy_move`);
   - ZERO foreign-grid or missing-grid region with log10 NFA at or below the threshold, covering at most 25%
     of the image; a missing-grid region also needs the main grid to be dense outside it and sparse inside
     (label `jpeg_history`);
   - CAT-Net and SAFIRE components both above their calibrated thresholds `t` and overlapping with IoU >= 0.3
     (label `inconsistent`, confidence high);
   - one learned map above its strong threshold `T` on a compact component (area <= 25%, solidity >= 0.5)
     (label `inconsistent`, confidence medium). Switched off in the recommended configuration, see results.
4. All candidate areas together over 50% of the image: abstain (`global_change`), because a global filter or
   a full VAE pass would light up everything.
5. Nothing accepted: `no_local_edits` only if every method ran and every learned score stayed under half its
   threshold; otherwise `inconclusive`.
6. The AI tile layer never creates a region; it only sets `likely_ai` on an accepted one.

Thresholds `t` (authentic p99.5) and `T` (p99.9 with at least 1000 images, else the authentic maximum plus
0.02) are fitted per input class (`jpeg`, `jpeg_low`, `nonjpeg`) on the calibration half of the authentic
photos only. The evaluation split is by source image, so the WhatsApp copy of a VISION photo never sits on the
other side of the split from its original.

## Known limits

- Fully regenerated edits (instruction editors, a whole-image VAE pass) and AI-upscaled images cannot be
  localized; the image-level Tribunal handles them, and the map must stay silent.
- Images under 384 px on the short side are never mapped (CocoGlide is 256x256 and always abstains).
- Copy-move after JPEG compression is weak: copies whose 8x8 blocks are not aligned rarely pass the strict
  a-contrario patch test (unit tests only assert the block-aligned case).
- CAT-Net needs the DCT coefficients; we estimate them from the decoded luma (`imageio.estimate_luma_coefficients`)
  instead of reading the file with `jpegio` (no wheels for Python 3.12/3.13 or macOS). On the CAT-Net example
  image the port reproduces the published output.
- EXIF orientation is not applied: maps are in stored pixel order, the UI must rotate them like the image.

## Integration proposal (not wired in)

### Analyzer shape

- New `ManipulationMapAnalyzer` in `analyzers/implementations/manipulation_map.py`, name `manipulation_map`,
  version `0.1.0`, MIME `image/jpeg`, `image/png`, `image/webp`. It calls `pipeline.analyze_bytes` and stores
  the map; it never votes on the AI axis (verdict always `inconclusive`, weight 0 in `seed_analyzers`).
- Queue `ml` (CPU worker), timeout 180 s, `torch.set_num_threads` from `MANIPULATION_THREADS` (default 6).
  Weights under `MANIPULATION_WEIGHTS_DIR` (fp32 state dicts, sha256 pinned in code, loaded with
  `weights_only=True`), shipped the way `make ship-retrained` ships the retrained detectors.
- Cost control: CAT-Net, ZERO, copy-move and tiles always; SAFIRE behind `MANIPULATION_SAFIRE=1` because it is
  the slowest piece (fixed 1024x1024 ViT-B pass) and only matters for the agreement rule. CAT-Net runs on
  8-pixel-aligned 1536 px tiles; above 12 MP the analyzer returns `abstain / too_large` instead of queueing a
  minute of CPU.
- Aggregation: add `manipulation_map` to `MANIPULATION_ANALYZERS`, but only `evidence.manipulation_suspected`
  (true when at least one high-confidence region exists) may move a verdict, and only to `authentic_edited`,
  never to fake. ELA leaves `MANIPULATION_ANALYZERS` and stays as raw evidence.
- The "whole image is AI" abstain rule belongs in the serializer: when the submission verdict is fake or
  likely fake, the detail response drops `map_url` and sets `status=abstain, reason=whole_image_ai`, so the
  analyzer itself does not wait for the other analyzers.
- `is_photo` comes from the existing `_photographic_score` in `clip_detector.py` (same screenshot / diagram
  rule the AI detectors use) plus the camera EXIF check.

### Evidence fields

```json
{
  "status": "regions_found | no_local_edits | inconclusive | abstain",
  "reason": "regions_accepted | no_region_passed | weak_signals | low_quality_jpeg | global_change | too_small | not_a_photo | whole_image_ai | too_large",
  "manipulation_suspected": true,
  "score": 0.0,
  "input_class": "jpeg | jpeg_low | nonjpeg",
  "regions": [
    {"bbox": [x0, y0, x1, y1], "kind": "copy_move | jpeg_history | inconsistent",
     "confidence": "high | medium", "methods": ["catnet", "safire"], "area_share": 0.04, "likely_ai": false}
  ],
  "map_path": "manipulation/<submission_id>.png",
  "map_url": "(presigned in AnalysisResultSerializer, like heatmap_path)",
  "map_size": [768, 512],
  "image_size": [4032, 3024],
  "method_scores": {"catnet": 0.12, "safire": 0.55, "zero_log10_nfa": 0.0, "copymove_matches": 0},
  "calibration": "2026-10-26 manipulation-map v0 (authentic p99.5 per input class)",
  "timings_s": {"catnet": 2.1, "zero": 0.4, "copymove": 0.3, "tiles": 0.6}
}
```

`bbox` is in original pixel coordinates of the stored file (before EXIF rotation). The map PNG is 8-bit
grayscale at up to 768 px on the long side, 0 outside accepted regions, so a viewer cannot read anything
into the background.

### Frontend overlay

- Replace `ELAHeatmapOverlay` with a `ManipulationMapOverlay` shown only when `status == regions_found`:
  the photo itself, the map on top in one warm colour at about 45% opacity (opacity slider kept), and a thin
  outlined box with a number for each region. Rotate the map with the same EXIF orientation as the photo.
- Legend under the picture, one line per region, using the plain wording below; high-confidence regions
  solid outline, medium dashed.
- `no_local_edits`, `inconclusive` and `abstain` show one quiet line of text and no picture at all, never an
  empty heatmap (the current ELA map always shows "some red", which reads as guilt).
- ELA moves into the raw-evidence drawer for staff (`showRaw`).

### Wording for teachers (RU / EN)

| case | Russian | English |
|---|---|---|
| title | Где фото могли изменить | Where the photo may have been changed |
| copy_move | Этот участок повторяет другой участок того же снимка: его могли скопировать внутри фото. | This area repeats another part of the same photo: it may have been copied within the image. |
| jpeg_history | У этого участка другая история сжатия, чем у остального снимка. Так бывает, когда фрагмент вставлен из другого изображения или перерисован. | This area was compressed differently from the rest of the photo. That happens when a piece is pasted from another image or redrawn. |
| inconsistent, high | Этот участок не согласуется с остальным фото: его могли вставить или перерисовать. | This area does not match the rest of the photo: it may have been pasted in or redrawn. |
| inconsistent, medium | Возможное несоответствие, посмотрите на этот участок внимательнее. | Possible mismatch, look at this area more closely. |
| likely_ai (extra line) | Участок похож на созданный ИИ. | This area looks AI-generated. |
| no_local_edits | Следов местного редактирования не нашли. Это не доказывает, что фото подлинное. | No signs of local editing were found. This does not prove the photo is genuine. |
| inconclusive | Для этого файла нельзя надёжно показать изменённые места (например, из-за сильного сжатия). | We can't reliably show edited areas for this file (for example, because of strong compression). |
| whole_image_ai | Снимок целиком похож на созданный ИИ, поэтому карту отдельных участков не показываем. | The whole picture looks AI-generated, so we don't show a map of separate areas. |
| global_change | Изменения затрагивают почти весь снимок (общий фильтр или перерисовка целиком), карта участков ввела бы в заблуждение. | The changes cover almost the whole photo (a global filter or a full redraw), so a map of areas would mislead. |
| too_small | Изображение слишком маленькое для карты. | The image is too small for a map. |
| footer | Карта показывает несоответствия, а не доказательство подделки. | The map shows inconsistencies, not proof of forgery. |

Never the word "fake" / "подделка" on a region; the teacher sees "may have been", "does not match".
